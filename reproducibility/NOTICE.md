# Provenance and licensing

All files in this bundle are copied verbatim from the SynGlue project codebase used to produce the
manuscript. `MANIFEST.csv` maps every file to its original repository-relative path and records its
SHA256, so each script can be traced to the exact source revision.

- Code is distributed under the project licence (MIT) unless a file states otherwise.
- Third-party comparator tools (PDP, PROTAC-STAN, PROTAC-DC50, TACK, DeLinker, DiffLinker, DiffSBDD,
  Pocket2Mol, PGMG, ShapeLinker, Gcoupler) are **not** bundled; each runner in `comparators/`
  documents how to obtain them.
- No model checkpoints, datasets, embeddings, or results are included.
